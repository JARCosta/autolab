Discord bot

CS2-style queue and Elo live in Discord. This page mirrors the shared data/boost/players.json stats the bot reads and updates. Queues and matches are controlled only in your server via slash commands.

Slash commands

Command Who What it does
/startqueue Server admins Creates a new joinable queue (optional title).
/kickfromqueue Host or admin Removes a member from the current queue.
/addtoqueue Host or admin Adds a member to the current queue.
/leaderboard Everyone Shows Elo and W–D–L in Discord (same data as the table below).
